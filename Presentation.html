02 — CONCEPT
สำหรับผู้เริ่มต้น

FTP คืออะไร?

LIST → ขอรายชื่อไฟล์ทั้งหมด
STOR → อัปโหลดไฟล์ขึ้น Server
RETR → ดาวน์โหลดไฟล์จาก Server
DELE → ลบไฟล์บน Server
ลำดับการทำงานของ FTP
01 Client เชื่อมต่อไปยัง Server (Port 21)
02 Login ด้วย Username / Password
03 ส่งคำสั่ง (LIST, STOR, RETR, DELE)
04 Server ตอบกลับตามคำสั่ง

05 — DOCKER
การ Config

Docker Setup

image: delfer/alpine-ftp-server
container: sprout-ftp-server
 
ports:
  - "21:21" # Control
  - "21100-21110" # Data
 
environment:
  USERS=admin|1234
  ADDRESS=127.0.0.1
 
volumes:
  ./ftp-data:/ftp/admin
USERS
สร้าง user: admin / รหัส: 1234
PORTS
เปิด Port 21 (Control) และ 21100-21110 (Passive Data)
VOLUMES
ผูกโฟลเดอร์ ftp-data กับ Container
IMAGE
Alpine Linux + vsftpd Server
