# 🌱 Sprout FTP

## โครงการ Sprout FTP เว็บฝากไฟล์รูปภาพ

### เนื้อหา

บริการที่ได้รับคืออะไร: บริการ FTP (File Transfer Protocol)

FTP คืออะไร?: File Transfer Protocol หรือ FTP คือโพรโทคอลมาตรฐานบนเครือข่ายคอมพิวเตอร์ที่ถูกออกแบบมาเพื่อใช้ในการแลกเปลี่ยนและจัดการไฟล์ระหว่างเครื่องคอมพิวเตอร์แม่ข่าย (Server) และเครื่องคอมพิวเตอร์ลูกข่าย (Client) โดยทำงานในลักษณะ Client-Server Model กล่าวคือ Client จะเป็นฝ่ายส่งคำร้องขอ (Request) ไปยัง Server เช่น ขอรายชื่อไฟล์, ขออัปโหลดไฟล์ หรือขอดาวโหลดไฟล์ และ Server จะเป็นฝ่ายตอบสนอง (Response) ตามคำร้องขอนั้นๆ

### ขอบเขตของโครงการ

1. **ผู้ใช้ระบบ**
   1.1 **ผู้ใช้ทั่วไป**
   1.1.1 สามารถอัปโหลดไฟล์จากเครื่องคอมพิวเตอร์ขึ้นไปยังเซิร์ฟเวอร์ FTP ผ่านหน้าเว็บ
   1.1.2 สามารถดาวโหลดไฟล์จากเซิร์ฟเวอร์ FTP มายังเครื่องคอมพิวเตอร์ของตนเอง
   1.1.3 สามารถดูรายการไฟล์และโฟลเดอร์ทั้งหมดที่เก็บอยู่ในเซิร์ฟเวอร์ FTP
   1.1.4 สามารถจัดการไฟล์ได้ เช่น ลบไฟล์ เปลี่ยนชื่อไฟล์ หรือสร้างโฟลเดอร์ใหม่

2. **ฟังก์ชันหลัก**
   2.1 **อัปโหลดไฟล์**
   2.1.1 ให้ผู้ใช้เลือกไฟล์จากเครื่องและอัปโหลดขึ้นไปเก็บบนเซิร์ฟเวอร์
   2.2 **ดาวโหลดไฟล์**
   2.2.1 ให้ผู้ใช้สามารถเลือกไฟล์ที่ต้องการและดาวโหลดลงมายังเครื่องตนเอง
   2.3 **ดูรายการไฟล์**
   2.3.1 แสดงรายการไฟล์และโฟลเดอร์ในรูปแบบตารางหรือลิสต์
   2.4 **การจัดการไฟล์**
   2.4.1 ผู้ใช้สามารถลบหรือเปลี่ยนชื่อไฟล์/โฟลเดอร์

### การทำงานและพอร์ตที่ใช้งาน

**พอร์ต 21**: พอร์ตควบคุม (Control Port)
- เปรียบเสมือน "สมอง" หรือ "ผู้จัดการ" ของการเชื่อมต่อ
- ทำหน้าที่รับ-ส่งคำสั่ง เท่านั้น ไม่ใช่ตัวไฟล์
- ตัวอย่างคำสั่ง:
  - USER/PASS: การยืนยันตัวตน (Login)
  - LIST: ขอรายชื่อไฟล์และโฟลเดอร์
  - STOR: คำสั่ง "เตรียมอัปโหลดไฟล์"
  - RETR: คำสั่ง "เตรียมดาวโหลดไฟล์"
- ข้อมูลที่วิ่งในช่องทางนี้จะมีขนาดเล็กมาก

**พอร์ต Data**: ช่องทางสำหรับข้อมูล (Data Port)
- หน้าที่: เปรียบเสมือน "ประตูขนส่งสินค้า" หรือ "ช่องทางด่วนพิเศษ"
- สิ่งที่ทำ: ใช้สำหรับรับ-ส่ง "ข้อมูลของไฟล์จริงๆ" ทั้งหมด
- ช่องทางนี้จะถูกเปิดขึ้นมาใช้ชั่วคราวเมื่อมีการอัปโหลดหรือดาวโหลดเกิดขึ้นเท่านั้น

### การทำงานร่วมกันของสองช่องทาง

โหมดที่เรียกว่า Passive Mode ซึ่งเป็นโหมดที่นิยมและปลอดภัยที่สุด มีขั้นตอนง่ายๆ ดังนี้:

1. โปรแกรมของเรา (Client) ติดต่อไปที่ พอร์ต 21 ของ Server เพื่อ Login และส่งคำสั่ง "ฉันต้องการอัปโหลดไฟล์"
2. Server ตอบกลับมาทางพอร์ต 21 ว่า "ได้เลย, ให้ไปที่ **ประตูขนส่งหมายเลข 21105 ของ Server แล้วเริ่มส่งข้อมูลไฟล์ทั้งหมดผ่านช่องทางนี้"
3. เมื่อส่งไฟล์เสร็จ ประตูขนส่งหมายเลข 21105 ก็จะถูกปิดลง

#### 3. ขั้นตอนการทำงานโดยละเอียด

**ขั้นตอนที่ 1: เริ่มต้นระบบ**
1. รัน Docker Compose เพื่อสร้าง Container ทั้งหมด
2. FTP Server (vsftpd) รันบนพอร์ต 21 และพอร์ต Data 21100-21110
3. Web Server (ASP.NET) รันและเชื่อมต่อกับ FTP Server

**ขั้นตอนที่ 2: ผู้ใช้เข้าถึงเว็บไซต์**
1. เปิดเบราว์เซอร์และเข้าเว็บไซต์
2. Web Server รับ Request และเชื่อมต่อกับ FTP Server
3. ดึงรายการไฟล์และโฟลเดอร์จาก FTP Server
4. ส่ง HTML Response กลับไปยังเบราว์เซอร์

**ขั้นตอนที่ 3: อัปโหลดไฟล์**
1. ผู้ใช้เลือกไฟล์และกดปุ่ม Upload
2. เบราว์เซอร์ส่ง HTTP POST Request พร้อมไฟล์
3. Web Server รับ Request และใช้ FluentFTP อัปโหลดไฟล์ไปยัง FTP Server
4. FTP Server บันทึกไฟล์ลง Storage
5. ส่ง Response กลับไปยังเบราว์เซอร์

**ขั้นตอนที่ 4: ดาวโหลดไฟล์**
1. ผู้ใช้กดปุ่ม Download
2. เบราว์เซอร์ส่ง HTTP GET Request
3. Web Server ใช้ FluentFTP ดึงไฟล์จาก FTP Server
4. ส่งไฟล์กลับไปยังเบราว์เซอร์ในรูปแบบ Binary

**ขั้นตอนที่ 5: ลบไฟล์**
1. ผู้ใช้กดปุ่ม Delete และยืนยัน
2. เบราว์เซอร์ส่ง HTTP POST Request
3. Web Server ใช้ FluentFTP สั่งลบไฟล์จาก FTP Server
4. ส่ง Response กลับไปยังเบราว์เซอร์

#### 5. การจัดการ Session และ Security

- **Session Management**: ใช้ Session ของ ASP.NET เพื่อจัดการสถานะผู้ใช้
- **Authentication**: ใช้ Username/Password สำหรับการเชื่อมต่อ FTP
- **File Validation**: ตรวจสอบประเภทไฟล์และขนาดไฟล์ก่อนอัปโหลด
- **Error Handling**: จัดการข้อผิดพลาดจากการเชื่อมต่อ FTP และการจัดการไฟล์

### Image บน Docker Hub

เราเลือกใช้ Image ชื่อ delfer/alpine-ftp-server ซึ่งเป็น Image ที่บรรจุ FTP Server ที่ชื่อว่า vsftpd (Very Secure FTP Daemon) เอาไว้เรียบร้อยแล้ว การใช้ Image สำเร็จรูปเช่นนี้ช่วยลดเวลาในการติดตั้งและตั้งค่า Server ลงไปได้อย่างมหาศาล เราสามารถดึง (pull) Image และรันเป็น Container ได้ด้วยคำสั่งเพียงไม่กี่บรรทัด

### ไฟล์ docker-compose.yml

```yaml
version: '3.8' # Docker Compose Version
services: # Services That we need
  ftp-server: # Ftp
    image: delfer/alpine-ftp-server
    container_name: sprout-ftp-server
    ports: # Port 21 for Sending and Recieve Data
      - "21:21"
      - "21100-21110:21100-21110"
    environment: # User Config
      - USERS=admin|1234
      - ADDRESS=127.0.0.1
      - MIN_PORT=21100
      - MAX_PORT=21110
    volumes: # Path
      - ./ftp-data:/ftp/admin
```

### การรันโปรเจค

1. ติดตั้ง Docker บนเครื่อง
2. รันคำสั่ง `docker-compose up` ในโฟลเดอร์โปรเจค
3. เปิดเบราว์เซอร์ไปที่ `http://localhost`
4. ใช้งาน FTP client ผ่านหน้าเว็บ
