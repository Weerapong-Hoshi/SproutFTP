ที่มาและความสำคัญ

  • FTP (File Transfer Protocol) เป็นโปรโตคอลมาตรฐานสำหรับการส่งไฟล์ระหว่าง Client และ Server
  • การใช้งาน FTP แบบเดิมต้องใช้โปรแกรม Client เช่น FileZilla ทำให้ไม่สะดวกในการเข้าถึงจากที่ไหนก็ได้
  • Web-based FTP Manager ช่วยให้ผู้ใช้สามารถจัดการไฟล์บน FTP Server ผ่านเว็บเบราว์เซอร์ได้โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม
  • เหมาะสำหรับองค์กรหรือบุคคลทั่วไปที่ต้องการความสะดวกในการจัดการไฟล์

วัตถุประสงค์

เพื่อพัฒนาระบบที่สามารถ อัปโหลดไฟล์ จากเครื่องคอมพิวเตอร์ขึ้นไปยัง FTP Server
เพื่อให้ผู้ใช้สามารถ ดูรายการไฟล์ ที่เก็บบน FTP Server ได้
เพื่อให้ผู้ใช้สามารถ ดาวน์โหลดไฟล์ จาก FTP Server ลงเครื่องได้
เพื่อให้ผู้ใช้สามารถ ลบไฟล์ ออกจาก FTP Server ได้

ขอบเขตของโครงงาน

In Scope

  • ระบบอัปโหลดไฟล์ขึ้น FTP Server
  • ระบบแสดงรายการไฟล์บน Server
  • ระบบดาวน์โหลดไฟล์จาก Server
  • ระบบลบไฟล์ออกจาก Server
  • แสดงข้อมูลไฟล์ (ชื่อ, ขนาด, วันที่แก้ไข)
  • แสดงข้อความแจ้งเตือน Error

Out of Scope

  • การสร้างโฟลเดอร์ใหม่
  • การเปลี่ยนชื่อไฟล์
  • การย้ายไฟล์ระหว่างโฟลเดอร์
  • ระบบ Login/Register
  • การแก้ไขเนื้อหาไฟล์
  • รองรับ FTPS/SFTP
